# МедиаКоми 🏠

Интерактивный симулятор оценки недвижимости в Республике Коми. Угадайте стоимость квартиры и получите баллы!

## 🎮 Как играть

1. Нажмите «Начать игру»
2. Вам покажут 10 случайных квартир из базы
3. Двигайте бегунок, чтобы назвать свою цену
4. Нажмите «Оценить» — увидите правильный ответ и заработанные баллы
5. После 10 раундов — итоговый результат

## 📊 Система баллов

| Точность | Баллы |
|----------|-------|
| ≤ 2%     | 100   |
| ≤ 5%     | 90    |
| ≤ 10%    | 75    |
| ≤ 15%    | 60    |
| ≤ 20%    | 45    |
| ≤ 30%    | 25    |
| ≤ 50%    | 10    |
| > 50%    | 5     |

## 🏆 Итоговые категории

- **Опытный инвестор** (700+ баллов) — отлично чувствуете рынок!
- **Щедрый инвестор** — склонны переплачивать за недвижимость
- **Скряга** — экономный инвестор, всегда торгуетесь

## 🚀 Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

## 📦 Сборка

```bash
npm run build
```

Результат в папке `dist/`

## 🛠 Технологии

- React 18 + TypeScript
- Vite
- Tailwind CSS 4
- Без тяжёлых библиотек

## 📱 Особенности

- Мобильная версия в приоритете
- Один экран = одна карточка
- Быстрая загрузка, минимальный трафик
- Security headers: CSP, Referrer-Policy, X-Frame-Options, nosniff, Permissions-Policy
- Standalone frontend-only
